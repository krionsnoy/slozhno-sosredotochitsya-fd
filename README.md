# Сложно сосредоточиться

Адаптивный лендинг с переключением цветовых тем (светлая / тёмная / авто).

Проект выполнен в рамках курса  Яндекс Практикума.

## О проекте

Лендинг посвящён проблеме концентрации внимания в современном мире.  
Сайт полностью адаптивен и поддерживает три режима отображения:

- **День** — светлая тема
- **Неон** — тёмная тема
- **Авто** — тема определяется автоматически по системным настройкам пользователя

## Технологии

- HTML5
- CSS3 (Grid, Flexbox, кастомные свойства, clamp)
- JavaScript (переключение тем)
- Адаптивная вёрстка (mobile-first)
- Доступность (aria-атрибуты)

## Функциональность

- Переключение тем в реальном времени
- Сохранение выбранной темы
- Автоматическое определение системной темы
- Полностью адаптивный дизайн (от 375px)
- Декоративные элементы (уголки, индикатор REC)
